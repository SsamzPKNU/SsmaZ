# 수학 문제 데이터 업데이트 안내 (2026-02-12)

> **대상**: 프론트엔드 개발자
> **영향 범위**: 과제 목록, 문제 렌더링, 오답 분석 화면

---

## 변경 요약

수학 유리수/순환소수 단원 문제 데이터(200문항)가 매핑 규칙에 맞게 재구성되었습니다.

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `question_type` | 전부 `SHORT_ANSWER` | `CHOICE` 13건 + `SHORT_ANSWER` 187건 |
| `difficulty` | 전부 `MEDIUM` | `EASY` 40건 / `MEDIUM` 62건 / `HARD` 98건 |
| `category` | 원본 question 컬럼 (38종) | 표준 카테고리 (17종) |
| `question_text` | `(pid-subid) value : question` | 한국어 지시문 형태 |
| `options` | 전부 `null` | CHOICE 유형만 JSON 배열 |
| Assignment `class_id` | `null` | `2` |

## 1. question_type 변경

CHOICE 유형이 추가되었습니다. 프론트에서 `question_type`에 따라 분기 처리가 필요합니다.

| question_type | 문항 수 | UI 처리 |
|---------------|---------|---------|
| `CHOICE` | 13건 | `options` 배열로 보기 렌더링 |
| `SHORT_ANSWER` | 187건 | 텍스트 입력 필드 |

### CHOICE 유형 세부

| problem_id | 문항 수 | options 예시 |
|------------|---------|-------------|
| 1 (분류형) | 8건 | `["자연수", "음의정수", "정수가아닌유리수", "유리수"]` |
| 38 (보기선택) | 4건 | `["ㄱ", "ㄴ", "ㄷ", "ㄹ", "ㅁ", "ㅂ", "ㅅ", "ㅈ"]` |
| 39 (보기선택) | 1건 | `["ㄱ 0", "ㄴ 0.101001000…", "ㄷ -23÷3", ...]` |

> **주의**: problem_id 1은 **복수 정답** 가능 (예: `correct_answer: "정수가아닌유리수/유리수"`)

## 4. question_text 형식 변경

```
# 변경 전
(4-2) 0.1010010001… : 순환소수○/×

# 변경 후
다음이 순환소수인지 판별하시오 (○/×): 0.1010010001…
```

프론트에서 `question_text`를 그대로 렌더링하면 됩니다.

---

## 5. correct_answer 형식

`/`로 구분된 다단계 정답이 포함될 수 있습니다.

| 유형 | correct_answer 예시 | 설명 |
|------|---------------------|------|
| 단일 정답 | `○`, `7`, `0.25` | 그대로 비교 |
| 복수 분류 | `정수가아닌유리수/유리수` | `/`로 구분된 복수 정답 |
| 다단계 풀이 | `100/26.2626…/99x=26/26/99` | 풀이 과정 포함 |
| 판별+수정 | `×/0.4̇` | 오답 시 올바른 표현 포함 |
