# [PRD] 프로젝트3 - 학원 관리 웹 서비스
> **최종 수정일**: 2026-02-03

## 1. 프로젝트 개요
- **목적**: 1인 및 소규모 학원을 위한 직관적인 출결/결제/학생 관리 시스템.
- **핵심 가치**: 복잡한 관리 툴 대신, 선생님과 원장이 가장 자주 사용하는 기능을 모바일/웹에서 빠르고 단순하게 처리함.

## 2. 사용자 역할 (User Roles)
- **ADMIN (원장님)**: 학원 정보 관리, 선생님 관리, 전체 학생 및 회계 데이터 조회.
- **TEACHER (선생님)**: 담당 반 학생 출결 체크, 데일리 로그 작성, 문자 리뷰 관리.
- **STUDENT (학생)**: 본인 출결 현황 조회, 학습 로그 확인, 미납 결제 정보 확인.

## 3. 핵심 기능 요구사항
### ① 학생 및 반 관리
- 학생 정보 등록/수정/삭제 및 특정 '반(Class)' 배정.
- 학생별 상태 관리(재원, 휴원, 퇴원).

### ② 출결 관리 (선생님 주체)
- 반별 학생 목록에서 **[등교, 하교, 지각, 결석, 조퇴]** 상태를 체크.
- **등하교 알림**: 체크 시 설정에 따라 학부모에게 실시간 알림톡/문자 발송 가능.
- **대시보드**: 전체 학생의 실시간 출결 현황을 한눈에 파악할 수 있는 통합 대시보드 제공.

### ③ 결제 및 수납 관리
- 학생별 결제 금액 및 결제 예정일 관리.
- 미납자 목록 자동 추출 및 수납 이력 기록.

### ④ 보안 및 시스템 안정성 (신규)
- **보안 강화**: JWT 기반 인증에 httpOnly 쿠키 및 CSRF 대응 적용으로 보안성 확보.
- **로그 시스템**: 모든 로그인 시도(성공/실패)를 기록하여 이상 징후 모니터링 지원.

### ⑤ 문자 리뷰 모델 (기구현 기능)
- 학원 운영에 대한 리뷰나 안내 사항을 문자로 전송하고 관리하는 모델.
- 출결 상황이나 데일리 로그와 연동하여 자동/수동 문자 발송 지원.

### ⑥ FAQ 챗봇 (신규)
- **RAG 기반 챗봇**: ChromaDB + Ollama를 활용한 학원 FAQ 자동 응답 시스템.
- **환각 방지**: 엄격한 프롬프트 및 컨텍스트 기반 답변으로 허위 정보 생성 방지.
- **캐싱 최적화**: 자주 묻는 질문에 대한 응답을 캐싱하여 응답 시간 10초 → 50ms 이내로 단축.
- **사전 Warm-up**: 서버 시작 시 FAQ 20개 질문에 대한 답변 사전 생성.

## 4. 사용자 흐름 (User Flow)
1. **로그인**: 학원에서 발급된 전용 계정(ID/PW)을 통한 로그인 (CSRF 및 보안 쿠키 적용).
2. **대시보드 진입**: 전체 학생 출결 및 오늘 예정된 스케줄 확인.
3. **출결 체크**: 학생 리스트 옆의 버튼 클릭 시 즉시 반영 및 부모 알림 선택.
4. **리뷰/알림**: 필요 시 문자 리뷰 모델을 통해 학부모에게 리포트 전송.
5. **FAQ 챗봇**: 학부모/학생이 수업료, 시간표, 환불 등 자주 묻는 질문에 대해 실시간 AI 답변 제공.
